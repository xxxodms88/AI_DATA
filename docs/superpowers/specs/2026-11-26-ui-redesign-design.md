# UI 리디자인 설계 (2026-11-26, 승인됨)

## 의도
숭실대 학생이 휴대폰으로 "언제 타야 덜 붐비는지"와 "막차 놓치면 어떻게 가야 싼지"를 바로 보게 한다.
발표 때 프로젝터에서도 깨지지 않아야 한다. 우선순위는 **휴대폰**.

## 목표 / 하지 않을 것
- 목표: 첫 화면에서 스크롤 없이 답(혼잡 수준 + 추천 시간)이 보인다. 분석 화면은 발표 근거로 남긴다.
- 하지 않음: React 등 새 프론트엔드로 다시 만들기, 분석 로직 변경.
- 실패로 볼 것: 템플릿처럼 보이는 카드 나열, 샘플 데이터를 실제처럼 보이게 하는 것.

## 접근 방법
| 방법 | 장점 | 단점 | 결정 |
|------|------|------|------|
| Streamlit 유지 + 테마·CSS·HTML 조각 | 분석 코드 그대로, 배포 쉬움 | 레이아웃 자유도 제한 | **선택** |
| React 프론트 + Python API | 자유로운 UI | 작업량 2~3배, 코드 이원화 | 제외 |

## 디자인 토큰
- 색: 7호선 올리브 `#747F00`, 안내판 남색 `#1F2A44`, 승강장 회색 `#ECEEEA`,
  붐빔 단계 연두 `#C9D38A` / 노랑 `#E8B931` / 진홍 `#B8322A`, 택시·LED 주황 `#F2A900`(막차 화면만)
- 글꼴: 서울남산체(역명·제목), Pretendard(본문). 앱 안에 서브셋으로 내장.
- 정렬: 왼쪽 정렬. 한 줄 80자 이하.

## 화면
- **언제 탈까(홈)**: 역명판(이전역 ◀ 역명 ▶ 다음역, 7호선 색 띠) → 한 문장 판정 → 한 문장 추천 →
  05~24시 혼잡 막대(목표·추천 시간 표시). 조건 변경은 아래 접힌 영역. 과감한 요소는 역명판 하나.
- **막차 놓쳤을 때**: 남색 배경, LED 주황 '막차 안내' 전광판에 추천 경로. 출발 시각 기본값은 지금(심야일 때).
- **분석 근거**(히트맵·피크·비교·역 유형): 같은 색 체계(혼잡 색 스케일)를 그래프에 적용.
- 메뉴: "쓰기" 2개 + "분석 근거" 묶음.

## 빌더 재량
- 막대·역명판 세부 크기, 그래프 템플릿 세부값, 문구 미세 조정.
