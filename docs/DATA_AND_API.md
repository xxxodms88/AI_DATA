## B. 키(인증키)를 발급받아야 하는 API

| # | 필수 | API | 발급처 | 무엇에 쓰나 | 넣는 곳 |
|---|------|-----|--------|-------------|---------|
| 1 | 필수* | 서울교통공사_역코드로 지하철 열차 시간표 검색 (OA-101) + 서울시 역코드로 지하철 막차시간표 정보 검색 (OA-109) | 서울 열린데이터광장 인증키 (data.seoul.go.kr 로그인 → 인증키 신청) | 22시 이후 열차 시각표 → `timetable.csv` | 변환 스크립트에서만 사용 |
| 2 | 필수* | 서울특별시_노선정보조회 서비스 (`getStaionsByRouteList`, `getRouteInfoItem`) | 공공데이터포털 serviceKey (data.go.kr 로그인 → 활용신청) | N버스 첫차·막차·배차간격 → `bus_schedule.csv` | 변환 스크립트에서만 사용 |
| 3 | 선택 | 카카오 로컬 API (주소 → 좌표) | Kakao Developers 앱의 REST API 키 | 목적지를 주소로 입력 | `.streamlit/secrets.toml` |
| 4 | 선택 | 카카오모빌리티 길찾기 API | 위와 같은 REST API 키 (카카오내비 API 사용 설정 필요) | 직선거리 추정 대신 실제 도로거리·택시요금 | `.streamlit/secrets.toml` |

\* 1·2번은 키 대신 손으로 채워도 됩니다. 막차 시각은 서울교통공사 사이버스테이션의 막차 시간표, N버스 첫차·막차·배차는 서울버스 앱에서 확인해 CSV에 직접 적으면 됩니다. 노선이 몇 개 안 되면 그 편이 빠릅니다.

## 키 보관 규칙

- 키는 **절대 GitHub에 올리지 마세요.** `.streamlit/secrets.toml`에 넣고, 이 파일은 `.gitignore`에 들어 있어야 합니다.
- 배포할 때는 Streamlit Cloud 앱 설정의 **Secrets** 칸에 같은 내용을 붙여 넣습니다.

```toml
# .streamlit/secrets.toml  (커밋 금지)
KAKAO_REST_API_KEY = "..."
SEOUL_OPEN_API_KEY = "..."
DATA_GO_KR_SERVICE_KEY = "..."
```
